# 思录（diary-thinker）

思录是一款个人日记与思考整理网页：记录日常想法，用 AI 提炼单篇日记，并按时间和分类汇聚为思考框架。现版本还包含思考主线、阶段目标、日记关联和目标复盘。

## 当前版本

请打开 `index2.html`。它是现版本；仓库默认入口 `index.html` 仍是较早版本。

- 新建、编辑、删除日记，按日期与分类筛选，自动保存草稿。
- AI 提炼单篇日记的核心观点、关键词、情绪倾向和行动项。
- 按时间与分类生成思考框架，复制 Markdown。
- 管理思考主线、阶段目标、进展和日记关联，生成目标复盘。
- 导入、导出 JSON 备份；备份不包含 API Key。

## 使用方法

1. 下载仓库，在浏览器中打开 `index2.html`。
2. 在“设置”中填写自己的 API Key，并检查 API 地址和模型。
3. 保存日记后使用“AI 提炼要点”；进入“思考框架”可汇总多篇记录。
4. 定期导出 JSON。导入会覆盖当前数据，请先备份。

## 数据与隐私

日记、思考主线和 API 设置保存在当前浏览器的 `localStorage` 中，不会自动跨设备同步。调用 AI 时，参与分析的日记内容会发送给所选 API 服务商。API Key 保存在浏览器本地，不写入仓库，也不包含在 JSON 备份中。请勿在公共设备保存密钥。

浏览器存储不是长期备份。更换浏览器、设备或页面地址前，请导出 JSON。浏览器直连 API 是否成功，还取决于服务商对当前页面地址的跨域支持。

## 开发状态

项目是无后端、无构建步骤的单文件 HTML 应用。现版本仍需修复草稿恢复、空列表、导入确认和批量关联等流程，并补充自定义分类、AI 结果编辑、完整范围汇聚与 Markdown 下载。跨设备同步尚未实现。
